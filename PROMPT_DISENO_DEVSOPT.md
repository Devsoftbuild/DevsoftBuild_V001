## 🎨 IDENTIDAD VISUAL Y COLORES

### Paleta de Colores Primaria

**Color Principal (Fondo Oscuro):**
- **Teal Oscuro/Deep Teal:** `#0a1a1f` o `#0d1e24`
- Uso: Fondos principales, secciones oscuras, navbar

**Color Secundario (Acentos):**
- **Teal Claro/Cyan Brillante:** `#00d4ff` o `#00e5ff` o `#1dd1e8`
- Uso: Botones CTA, enlaces, hover effects, elementos destacados, gradientes

**Color Terciario (Texto y Elementos):**
- **Blanco:** `#ffffff`
- Uso: Textos principales, iconos, elementos sobre fondos oscuros

**Colores Complementarios:**
- **Teal Medio:** `#1a3a47` (para cards, secciones intermedias)
- **Gris Teal:** `#2a4a57` (para elementos secundarios)
- **Negro Suave:** `#000000` con opacidad (para overlays)

### Estilo Visual
- **Estética:** Moderna, tech, digital, profesional
- **Patrón de Fondo:** Grid sutil (como en el logo) - líneas de grid en teal muy suave
- **Tipografía:** Sans-serif moderna, tech-friendly (Montserrat, Inter, Poppins, o similar)
- **Efectos:** Gradientes sutiles, glow effects en elementos importantes, animaciones suaves

## 🎯 CARACTERÍSTICAS TÉCNICAS Y UX

### Responsive Design
- **Breakpoints:**
  - Mobile: < 768px
  - Tablet: 768px - 1024px
  - Desktop: > 1024px
  - Large Desktop: > 1440px

### Animaciones y Efectos
- **Scroll Animations:** Fade-in, slide-up al hacer scroll
- **Hover Effects:** Transform scale, glow, cambio de color
- **Loading:** Skeleton screens o spinner moderno
- **Transitions:** Suaves (0.3s ease)

### Performance
- **Optimización de Imágenes:** WebP, lazy loading
- **Código Minificado:** CSS y JS minificados en producción
- **CDN:** Para assets estáticos
- **Caching:** Headers apropiados

### SEO
- **Meta Tags:** Título, descripción, keywords
- **Open Graph:** Para redes sociales
- **Schema Markup:** Structured data
- **Sitemap:** XML sitemap
- **Robots.txt:** Configurado

### Accesibilidad
- **WCAG 2.1:** Nivel AA mínimo
- **Contraste:** Texto legible en todos los fondos
- **ARIA Labels:** Para elementos interactivos
- **Keyboard Navigation:** Navegación completa con teclado

## 📐 ESPECIFICACIONES DE DISEÑO

### Tipografía
- **Títulos:** Montserrat, Inter, o Poppins (Bold 700)
- **Cuerpo:** Inter, Roboto, o Open Sans (Regular 400, Medium 500)
- **Tamaños:**
  - H1: 48px - 64px (desktop), 32px - 40px (mobile)
  - H2: 36px - 48px (desktop), 28px - 36px (mobile)
  - H3: 24px - 32px (desktop), 20px - 24px (mobile)
  - Body: 16px - 18px
  - Small: 14px

### Espaciado
- **Padding Secciones:** 80px - 120px (desktop), 40px - 60px (mobile)
- **Gap entre elementos:** 24px - 32px
- **Container Max Width:** 1200px - 1400px

### Bordes y Sombras
- **Border Radius:** 8px - 12px (cards, botones)
- **Box Shadow:** Sutil, con color cyan en elementos destacados
- **Borders:** 1px - 2px, color cyan para acentos

### Botones
- **Primary:** Fondo cyan, texto blanco, padding 12px 32px
- **Secondary:** Outline cyan, texto cyan, fondo transparente
- **Hover:** Transform scale(1.05), glow effect

## 📝 NOTAS ADICIONALES

1. **Logo:** El logo debe estar presente en todas las páginas, preferiblemente en el navbar
2. **Consistencia:** Mantener la paleta de colores en toda la página
3. **Call-to-Actions:** Múltiples CTAs estratégicamente ubicados
4. **Velocidad:** La página debe cargar en menos de 3 segundos
5. **Mobile-First:** Diseñar primero para móvil, luego escalar a desktop
6. **Testing:** Probar en múltiples navegadores y dispositivos
